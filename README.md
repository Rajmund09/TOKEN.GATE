# 🛡️ TOKEN.GATE
### Industrial-Grade Multi-Tenant Access Management System

**TOKEN.GATE** is a high-security, multi-tenant industrial access management platform designed for seamless event hosting and identity verification. Built with a "Security-First" philosophy, it combines vibrant modern aesthetics with robust backend auditing and protocol isolation.

## 🚀 Key Features

### 1. Dynamic Host Registration
Event hosters can register their own sessions with a **Custom Form Builder**. Add dropdowns, radio buttons, and text fields dynamically to gather guest data specific to your event.

### 2. Dual-Gate Security Protocol
A strict separation between **Hoster Terminals** and the **Superior Mainframe**. Protocol isolation ensures that Master credentials only work in the Secure Override portal.

### 3. Real-Time QR Pass Generation
Verified guests receive encrypted QR-code passes instantly. The built-in **Gate Controller** terminal allows managers to scan or manually verify access signals in real-time.

### 4. Permanent Audit Vault
An immutable ledger of every system interaction. From event creation to guest entry, every action is logged with high-precision timestamps for superior oversight.

### 5. Production Shield
- **Rate Limiting**: Intelligent brute-force protection.
- **Security Headers**: X-Frame, X-Content-Type, and XSS protection enabled.
- **Data Isolation**: Localized JSON vaults with automated session management.

## 🛠️ Technology Stack
- **Backend**: Python / Flask
- **Frontend**: Vanilla JS (ES6+), CSS3 (Industrial Glassmorphism)
- **Security**: Werkzeug (Scrypt Hashing), AES-256 Encryption (Simulation)
- **Email**: SMTP Secure Uplink (Google App Protocol)

## 📦 Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-username/TOKEN.GATE.git
   cd TOKEN.GATE
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment**
   Create a `.env` file based on the `DEPLOY.md` template.

4. **Initialize Terminal**
   ```bash
   python app.py
   ```
